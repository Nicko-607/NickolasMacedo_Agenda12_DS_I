# Primeiro projetos de HTML
Este projeto em HTML foi criado para praticar a estrutura básica de um documento HTML, incluindo elementos como títulos, parágrafos, listas e links. O objetivo é familiarizar-se com a sintaxe do HTML e entender como criar uma página web simples.

📊A página demonstra sites favoritos em formato de uma lista, seguida de uma legenda e um link para acessar os sites.
